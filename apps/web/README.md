# Kite web app

Next.js 16 app: the landing page, the `/console` product, and the server routes.
Setup, commands, environment variables and the full documentation are in the [repository README](../../README.md).

```
src/app/           pages and API routes (app/api/*)
src/components/    landing/ (marketing page), console/ (product UI), shared logo and charts
src/lib/           ai/ (private AI features and their checks), market/ (prices, history, yields),
                   near/ (wallet, vault calls, swap status), preview/ (no-wallet engine),
                   server/ (route guards, 1Click client), and shared assets, plans, mix, store
```
